01 / The Challenge

Planetary Defense & Public Situational Awareness

  • Thousands of Near-Earth Objects (NEOs) pass close to Earth's orbit every year.
  • Raw astronomical orbital data is complex, fragmented, and hard for the general public and students to interpret.
  • There is a critical need for intuitive, real-time visualization of potential impact hazards.

Slide 2 of 5

02 / The Solution

CosmoScope Web Telemetry Dashboard

🛰️ Real-Time Ingestion

Automatically streams daily asteroid flyby telemetry from NASA's NeoWs API.

⚠️ Hazard Indexing

Calculates miss-distance in Lunar Distance (LD) units and categorizes impact risks.

📊 Dynamic Telemetry Charts

Interactive visual comparisons between asteroid diameter (meters) and velocity (km/h).

🔭 Daily APOD Discovery

Features NASA's daily high-resolution deep space imagery and scientific context.

Slide 3 of 5

03 / Data & Architecture

NASA Open Data Integration

NASA NeoWs REST API: Powers real-time asteroid diameter, velocity, and trajectory coordinates.

NASA APOD API: Provides verified scientific metadata and high-definition imagery.

Architecture: Zero-dependency frontend architecture ensuring 100% uptime, fast response times, and zero server hosting overhead.
