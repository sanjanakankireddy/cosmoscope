# CosmoScope: Near-Earth Asteroid & Deep Space Monitor
**Official Project for NASA Space Apps Challenge 2026 – Raipur Local Event**
*Theme: The Next Frontier*

---

## 🌌 Project Summary
CosmoScope is an open-source interactive telemetry dashboard developed for the NASA Space Apps Challenge 2026. It interfaces directly with NASA's open APIs to stream real-time orbital characteristics of Near-Earth Objects (NEOs), compute close-approach hazard ratings, and bring astrophysical imagery and science to educators, students, and citizens.

---

## 🚀 Key Capabilities
- **Real-Time Asteroid Tracking**: Direct ingestion from NASA's Near-Earth Object Web Service (`NeoWs`).
- **Hazard Classification**: Instant assessment of orbital proximity and potential impact hazards (using Lunar Distance metrics).
- **Interactive Telemetry Visualization**: Dynamic Chart.js visualizations contrasting estimated asteroid diameter against velocity.
- **Astronomy Picture of the Day (APOD)**: Daily high-resolution scientific photography paired with researcher documentation.

---

## 📡 NASA Data Sources Used
- **NASA NeoWs API**: `https://api.nasa.gov/neo/rest/v1/feed`
- **NASA APOD API**: `https://api.nasa.gov/planetary/apod`
- **NASA Open Data Portal**: `https://data.nasa.gov/`

---

## 🛠️ Technology Stack
- **Frontend**: HTML5, TailwindCSS, Chart.js, FontAwesome
- **Data Ingestion**: Fetch API (Async JavaScript)
- **Deployment**: Standalone Single-Page Application (compatible with GitHub Pages, Vercel, Netlify)
